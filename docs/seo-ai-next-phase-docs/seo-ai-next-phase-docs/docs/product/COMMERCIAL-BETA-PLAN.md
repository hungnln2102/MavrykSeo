# Commercial Beta Plan

## Mục tiêu

Kiểm chứng rằng Agency dùng platform trong workflow thật và sẵn sàng trả
tiền.

## Pilot profile

Ưu tiên một nhóm nhỏ Agency/SEO teams có: - nhiều client projects; - GSC
đang hoạt động; - rank tracking/content workflow thật; - willingness to
give structured feedback.

## Success signals

-   onboarding thành công;
-   first value nhanh;
-   weekly active projects;
-   recommendations accepted;
-   actions completed;
-   reports viewed/shared;
-   repeated use without developer assistance;
-   willingness to pay;
-   cost-to-serve hợp lý.

## Quan sát cần thu

-   module nào mở đầu tiên;
-   workflow nào vẫn phải dùng Sheets/Notion/ClickUp/Semrush;
-   detector nào bị bỏ qua;
-   action nào có giá trị;
-   report nào client cần;
-   permission/collaboration gaps;
-   data freshness complaints.

## Exit criteria

Chỉ mở rộng mạnh feature set khi: - core workflows ổn định; - không có
blocker security/data integrity; - pilot users quay lại; - Action Center
tạo giá trị; - reporting đủ dùng với client; - unit economics có thể
kiểm soát.
