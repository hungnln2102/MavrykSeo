# SEO Detector Specification

Mỗi detector là IP của platform và phải version hóa.

## Detector Template

-   ID
-   Definition
-   Input data
-   Preconditions
-   Algorithm
-   Thresholds
-   Confidence
-   Evidence
-   Recommended action
-   Severity/Priority mapping
-   Version
-   Tests
-   Known limitations
